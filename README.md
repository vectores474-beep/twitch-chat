# Nexus Stream 📱💬

**Nexus Stream** — это продвинутый, полностью кастомный мобильный клиент для Twitch-чата, разработанный с акцентом на скорость работы, удобство модерации и мобильную оптимизацию. Проект написан на чистом веб-стеке (HTML5/JS) с использованием библиотеки Comfy.js и упакован в нативное Android-приложение, а также поддерживает запуск на iOS.

---

## 🚀 Ключевые возможности

### 👥 Управление профилями и сессиями
* **Мультиаккаунтность:** Быстрое переключение между учетными записями прямо во время стрима.
* **Импорт и экспорт данных:** Полный бэкап и перенос настроек, OAuth-токенов, Client ID и списков каналов с помощью структурированных JSON-строк через буфер обмена (`localStorage`).
* **Быстрый старт:** Удобное сохранение параметров подключения без необходимости каждый раз вводить данные вручную.

### 🛠 Инструменты стримера и интерактив
* **Управление прогнозами (Predictions):** Создание и мониторинг Twitch Predictions прямо с мобильного устройства в несколько тапов.
* **Опросы (Polls):** Быстрый запуск голосований для зрителей и отслеживание результатов в реальном времени.
* **Интерактивные меню:** Выпадающие и боковые панели со списком кастомных быстрых действий.
* **Работа с баллами канала (Channel Points):** 
  * Для тех, у кого на канале настроены **награды за баллы**, приложение позволяет отслеживать пользовательские запросы и взаимодействие со зрителями.
  * *Что нужно нажимать:* В интерфейсе управления и меню инструментов предусмотрены специальные кнопки активации для мониторинга пользовательских наград, отправки быстрых ответов и подтверждения действий зрителей, потративших баллы.

### 🛡 Модерация и безопасность
* **Контроль чата:** Мгновенная выдача тайм-аутов и перманентных банов нарушителям.
* **Интерфейс команд:** Удобный доступ к чат-командам и служебным функциям стримера в пару кликов.

### 🎨 Интерфейс, дизайн и UX
* **Адаптивный дизайн:** Интерфейс спроектирован с учетом мобильной специфики (компактное расположение элементов, читаемый шрифт, оптимизированные отступы).
* **Кастомное брендирование:** Уникальная фирменная иконка приложения и настроенная цветовая палитра экрана-заставки (Splash Screen).
* **Управление жестами:** Интуитивная навигация с поддержкой свайпов (например, свайп вправо для открытия бокового меню).
* **Темы и локализация:** Переключаемые темы оформления и поддержка нескольких языков.

## 🔑 Инструкция: Как настроить токены и подключение

Для полноценной работы приложения (отправка сообщений, модерация, опросы и баллы) вам понадобятся данные разработчика Twitch:

1. **Client ID:** 
   * Перейдите в [Twitch Developer Console](https://dev.twitch.tv/console).
   * Создайте новое приложение (Add Application), укажите имя и в качестве OAuth Redirect URL пропишите `http://localhost`.
   * Скопируйте полученный **Client ID**.
2. **OAuth Token:**
   * Сгенерируйте токен с необходимыми правами доступа (например, через генераторы вроде *Twitch Token Generator* с нужными скоупами для чата, управления прогнозами и баллами).
   * Скопируйте полученный токен (начинается с `oauth:` или идет в чистом виде).
3. **Ввод данных в приложении:**
   * Откройте приложение, перейдите в настройки профиля и вставьте свои **Channel** (название канала), **Client ID** и **OAuth Token**.
   * При желании вы можете экспортировать готовый профиль в JSON-строку, чтобы быстро переносить его на другие устройства.

## 📥 Как установить приложение

### 🤖 Для Android:
1. Перейдите в раздел **[Releases](https://github.com/vectores474-beep/twitch-chat/releases)** справа на странице репозитория.
2. Скачайте свежий `.apk` файл.
3. Разрешите установку из неизвестных источников на телефоне и установите приложение.

### 🍏 Для iOS (iPhone / iPad):
*Поскольку у iOS нет прямой установки `.apk` файлов, приложение устанавливается через встроенный браузер Safari:*
1. Откройте страницу проекта (или веб-версию) в браузере **Safari** на вашем iPhone.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелочкой вверх в нижней панели).
3. Выберите пункт **«На экран “Домой”»** и подтвердите добавление.
4. Иконка приложения появится на рабочем столе, и оно будет работать как полноценная программа на весь экран.
